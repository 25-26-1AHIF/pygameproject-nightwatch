5. Spielgrafiken (Sprites)
--------------------------
Monster-Sprites (assets/monster_sheet.png) und Spieler-Sprites
(assets/player_sheet.png) wurden vollständig selbst gezeichnet. (Aseprite + Adobe Photoshop 2026)

Für die Erstellung der Wände, Böden, Parkette, Teppiche usw. wurde
pygame.draw + das Python Package "Pillow" verwendet.

Somit werden keine externen Assets außer die (selbstgezeichneten) Spieler und Monster Assets benötigt.


6. Sounds
---------
Alle Sounds (Schritte, Taschenlampen-Klick, Dash, Alert, Jumpscare,
Herzschlag, Umgebungsgeräusche) wurden synthetisch generiert.
Werkzeuge: Python wave-Modul + NumPy.
Keine externen Audio-Dateien eingebettet.


7. Menü- und Pause-Hintergrundbilder (KI-generiert)
----------------------------------------------------
assets/menu_bg.png   – Hintergrundbild des Hauptmenüs
assets/pause_bg.png  – Hintergrundbild des Pause-Menüs

Diese beiden PNG-Dateien wurden mit ChatGPT Image (DALL-E, OpenAI)
generiert. Prompt-Stil: dunkles Pixel-Art-Horror-Setting, Nachtszene
mit Mond, Laterne und Monster in einer Tür.

Die Bilder werden ausschließlich als dekorativer Hintergrund in den
Menü-Screens verwendet. Die gesamte Spielgrafik während des Spiels
ist prozedural durch Code erzeugt.


8. KI-Unterstützung im Code (gekennzeichnete Stellen)
------------------------------------------------------
Algorithmisch anspruchsvolle Abschnitte wurden mit Claude Opus 4.8
(Anthropic) entwickelt. Diese Stellen sind im Code eindeutig markiert:

    # KI CODE ANFANG
    # Claude Opus 4.8
    # Prompt: "..."
    ...
    # KI CODE ENDE

Betroffene Dateien und Abschnitte:

- src/main.py
    ZoomCamera-Klasse (Lerp-Zoom-Kamerasystem)

- src/game/monster.py
    Monster._bewege()-Methode
    (Bewegung mit Vektornormalisierung, Wandkollision, BFS-Pfad)

- src/game/lighting.py
    Lighting._filmkorn_erstellen() – Film-Grain via NumPy
    Lighting._lichtkegel_zeichnen() – Taschenlampen-Lichtkegel-Polygon

- src/game/utils.py
    bfs_path() und next_waypoint() – BFS-Wegfindung auf Navigationsgraph

Die PauseMenu-Klasse (ursprünglich KI-markiert) wurde im Zuge der
Vereinfachung vollständig durch eigenen einfacheren Code ersetzt.
